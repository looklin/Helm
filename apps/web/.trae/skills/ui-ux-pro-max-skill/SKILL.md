# UI/UX Pro Max Skill

该技能为构建专业级的 UI/UX 提供设计智能和最佳实践。它集成了行业领先的设计原则，并能根据特定的技术栈（如 React + Tailwind）提供针对性的指导。

## 核心功能

1. **设计系统生成**：快速生成调色板、字体排印、间距和阴影等设计规范。
2. **UX 最佳实践**：提供关于交互设计、信息架构和用户流程的专业建议。
3. **无障碍检查**：验证 UI 设计是否符合 WCAG 标准。
4. **特定领域搜索**：针对金融、医疗、电商等特定行业提供设计灵感和规范。
5. **技术栈优化**：提供针对 React, Vue, Tailwind CSS 等现代前端框架的 UI 实现建议。

## 何时调用

- 当用户请求改进界面的视觉效果或用户体验时。
- 当需要为新项目建立设计语言或设计系统时。
- 当用户询问特定的 UI 模式（如仪表盘、登录页面、复杂表单）的最佳实践时。
- 在交付代码前，进行 UI/UX 抗压测试或防错检查。

## 使用示例

- "为这个仪表盘设计一个现代感十足的深色模式配色方案。"
- "检查这个表单的无障碍性并提供改进建议。"
- "为金融应用提供一套符合行业标准的字体排印规范。"
- "如何优化这个移动端导航栏的用户体验？"
